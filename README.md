# coteve — Unveil Your Smile (베일 닦기 웹 체험)

웹캠 영상 위에 컬러 베일이 덮여 있고, 손날로 화면을 쓸면 손을 부드럽게 따라가는 둥근 붓이 손이 지나간 길(호)을 따라 베일을 걷어 선명한 얼굴이 드러나는 웹 체험입니다. 닦인 곳은 5.5초 동안 선명하게 유지된 뒤 잉크 번지듯 흐려지며 퍼지고, 베일이 다시 덮입니다. (사진 카운트다운 중에는 멈춤)

- 베일 컬러 4종 선택 (분홍 #FF80A0 / 보라 #AB7EFF / 하늘 #80EAFF / 초록 #80FF8A), 처음 시작은 보라색
- 첫 화면·체험 화면 상단 중앙에 작은 로고 (촬영한 사진에는 들어가지 않음)
- 손을 펴면 손바닥으로 넓게, 검지만 펴면 손가락 끝으로 얇게 닦임
- '처음으로' 버튼으로 홈 화면 복귀 (카메라도 꺼짐)
- 하단 아이콘 버튼: [베일 컬러 · 다시 체험하기] [촬영 셔터] [사진/영상 선택] (모바일에서는 더 작게)
  - 베일 컬러는 지금 컬러 원 하나만 보이고, 누르면 위로 다른 컬러가 펼쳐짐 (촬영 화면에서만 표시)
- 촬영: '사진 / 영상' 선택 → 3초 카운트다운 → 화면 그대로(같은 비율, 로고·문구 없이) 저장 또는 공유
  - 영상은 최대 15초, 가능하면 MP4(안 되는 브라우저는 WebM)로 저장

## 실행 방법
1. 터미널에서 이 폴더로 이동: `cd ~/Desktop/Coteve_Ai`
2. 서버 켜기: `node server.js`
3. Chrome에서 http://localhost:5173 열기 → "체험 시작하기" → 카메라 "허용"
4. 끝낼 때는 터미널에서 `Control + C`

## 테스트 주소
- `http://localhost:5173/?test` : 카메라 없이 레퍼런스 이미지 + 마우스 드래그로 그래픽 확인
- `http://localhost:5173/?mouse` : 카메라 + 마우스 드래그 함께 사용

## 파일 구성
- `index.html`, `styles.css` : 화면과 버튼, 문구
- `js/veil-renderer.js` : 베일 그래픽 (블러·컬러·Inner Glow·다시 덮이기). 맨 위 `LOOK` 값으로 유지 시간/번짐/투명도 조절
- `js/wipe-controller.js` : 닦기 동작 판단, 손이 지나간 길 기록. 맨 위 `WIPE` 값으로 민감도 조절
- `js/capture.js` : 사진 촬영·영상 녹화, 저장/공유
- `js/hand-tracker.js` : MediaPipe 손 인식, 손바닥/손가락 판단. 맨 위 `SENSITIVITY` 값으로 인식 민감도 조절
- `js/app.js` : 전체 흐름
- `server.js` : 내 컴퓨터에서 미리보기용 간단한 서버

## 배포 시 참고
카메라는 보안상 `https://` 주소(또는 localhost)에서만 작동합니다. 정적 파일만으로 구성되어 있어 Vercel, Netlify, GitHub Pages 등에 그대로 올릴 수 있습니다. (`server.js`는 배포에 필요 없음)
